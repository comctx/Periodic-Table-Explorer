Scientific Accuracy Disclaimer

Every effort has been taken to ensure true and accurate facts concerning the 118 elements throughout this app. The information is believed to be highly accurate, though absolute accuracy cannot be guaranteed.

Reference values can differ with source conventions, measurement conditions and new discoveries.

Scientific References

Scientific sources consulted for element information include:

  • Royal Society of Chemistry — Periodic Table: chemical properties, uses and discovery histories.
  • IUPAC/CIAAW — Abridged Standard Atomic Weights 2024: recommended standard atomic weights.
  • NIST — Atomic Spectra Database: atomic structure and ionization information.
  • PubChem — Periodic Table: reference element properties.

External reference links need an internet connection and may reflect different scientific conventions.
