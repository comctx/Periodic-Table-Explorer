About & Photo Credits

Periodic Table Explorer is a DONCO-BAYCITY™ app covering all 118 recognized elements. Element photographs are saved inside the app so they do not need to be downloaded each time an element is opened.

Each element page shows its individual image credit and license when applicable. For elements that are too rare or short-lived for a normal visible sample photograph, the app explains that instead of showing a misleading picture.
